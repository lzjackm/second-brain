# Brain

The owner's distilled judgment. Every lead, agent and reviser loads it before drafting. Onboarding copies this folder to `brain/`, which is yours: edit it freely; template updates never touch it.

## Rule format

One rule per bullet, with a stable ID, the rule, and where it came from:

`- **S03** Rule text. *Source: <the owner, YYYY-MM-DD, or the log entries it came from>.*`

ID prefixes: `G` guardrails, `P` principles, `S` style, `R` priorities, `M` mediums, and one letter per area you add (for example `W` for a "work" area).

## Changing a rule

- A change adds a new rule and marks the old one `*Superseded by S07.*`, so the reason for every change can be traced.
- The daily distill proposes rules as `brain_rule` queue items, with the evidence. The owner approves, edits or rejects; the executor applies approved rules.
- Prompts cite some rules by ID (G01, G02, G07, G12, P01, P03, P09, P16, P17, P20, P21, P28, S10 to S13, S16, S17). Keep those IDs when you reword them.
